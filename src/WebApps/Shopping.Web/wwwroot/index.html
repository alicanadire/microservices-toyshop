🏪 .NET 8 Microservices E-Commerce Application

⚠️ Development Mode Notice

You are currently viewing static files only. This is a .NET microservices application that requires Docker Compose to run the full application with all services.

📋 Project Overview

This is a comprehensive e-commerce microservices application built with .NET 8, implementing modern architectural patterns including:

  • Domain Driven Design (DDD)
  • Command Query Responsibility Segregation (CQRS)
  • Event-Driven Architecture
  • Clean Architecture
  • Vertical Slice Architecture

🔧 How to Run the Complete Application

To run the full microservices application, you need:

  1. Docker Desktop - Install from docker.com
  2. .NET 8 SDK - Install from dotnet.microsoft.com
  3. Visual Studio 2022 or VS Code (optional but recommended)
🚀 Quick Start with Docker Compose:
# Navigate to the src directory cd src # Build and start all services docker-compose -f docker-compose.yml -f docker-compose.override.yml up -d # Wait for all services to start (takes a few minutes) # Then visit: https://localhost:6065

🏗️ Microservices Architecture

🛍️ Catalog API

Port: 6000

Product management service with PostgreSQL database. Implements minimal APIs and CQRS pattern.

🛒 Basket API

Port: 6001

Shopping cart service with Redis cache and gRPC communication with Discount service.

💰 Discount gRPC

Port: 6002

High-performance discount service using gRPC with SQLite database.

📦 Ordering API

Port: 6003

Order management service implementing DDD, CQRS with SQL Server and RabbitMQ.

🌐 YARP API Gateway

Port: 6004

Reverse proxy gateway with rate limiting and routing configuration.

🖥️ Shopping Web UI

Port: 6005

ASP.NET Core Razor Pages frontend application with Bootstrap 4.

🗄️ Databases & Infrastructure

  • PostgreSQL - Catalog & Basket databases
  • SQL Server - Ordering database
  • SQLite - Discount database
  • Redis - Distributed caching
  • RabbitMQ - Message broker
  • Docker - Containerization

🔗 Service URLs (when running with Docker)

Shopping Web UI: https://localhost:6065 API Gateway: https://localhost:6064 Catalog API: https://localhost:6060 Basket API: https://localhost:6061 Discount gRPC: https://localhost:6062 Ordering API: https://localhost:6063 RabbitMQ Management: http://localhost:15672 (guest/guest)
